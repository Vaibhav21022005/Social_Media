# 🌐 Social Media App

A full-stack social media web application where users can connect, share posts, like, comment, and interact with each other.

---

## 📌 Project Overview

This project is built using a modern full-stack architecture with **React (Frontend)** and **Node.js + Express (Backend)**, along with **MySQL database**.

It allows users to create accounts, share posts, like, comment, and manage relationships with other users.

---

## 🚀 Features

* 🔐 User Authentication (Login / Register)
* 👤 User Profile Management
* 📝 Create, Update, Delete Posts
* ❤️ Like / Unlike Posts
* 💬 Comment on Posts
* 👥 Follow / Unfollow Users
* 🌓 Dark Mode Support
* 📱 Responsive Design

---
